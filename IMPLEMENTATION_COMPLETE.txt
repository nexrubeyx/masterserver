   - Fast rectangle-based queries for viewports

   - Low resource usage
   - Fast startup (~2 seconds)

✅ Optional Client Build
   - Accept "bld" messages from clients
   - In-memory object placement
   - Requires ALLOW_CLIENT_BUILD=true

--------------------------------------------------------------------------------
HOT-RELOAD FEATURES
--------------------------------------------------------------------------------

Template Changes:
  1. Edit any file in config/templates/*.json
  2. Server automatically reloads templates
  3. Broadcasts updated obj_tpl to all clients

Map Changes:
  1. Edit maps/mundo1.json objects array
  2. Server automatically detects changes
  3. Broadcasts updated o for affected tiles

Add New Templates:
  1. Create config/templates/mytemplate.json
  2. Server automatically loads it
  3. Broadcasts to all clients

--------------------------------------------------------------------------------
WEBSOCKET PROTOCOL
--------------------------------------------------------------------------------

Server → Client on Connection:
  1. obj_tpl - Complete template catalog
  2. o       - Objects in initial viewport

Server → Client on Hot-Reload:
  - obj_tpl - When templates change
  - o       - When map objects change

Client → Server (Optional):
  - bld - Build object (requires ALLOW_CLIENT_BUILD=true)
    Format: { "type": "bld", "tpl": "torch", "x": 10, "y": 5 }
